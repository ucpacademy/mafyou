# MAFYOU

Next.js motorcycle storefront for MAFYOU, based in Marrakech, with a photo-led showroom story, product pages and WhatsApp inquiries (wa.me/212604556403).

The interface supports English, French and Arabic (including right-to-left layout), plus a light/dark theme switch. Bike details and photography are demo references and should be confirmed with the shop before publication.

```
npm install
npm run dev
```
